Esta página documenta cómo creo webs, apps y scripts usando solo Termux en Android.

🛠️ Funciones de Termux que uso

  • pkg install python nodejs git - Instalar lenguajes
  • termux-setup-storage - Acceder a archivos del cel
  • termux-api - Usar cámara, GPS, SMS desde código
  • sshd + git + GitHub Pages - Subir proyectos sin PC
  • python -m http.server 8000 - Probar webs local
